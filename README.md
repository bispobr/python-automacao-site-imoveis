# python-automaçaoo-imoveis

Este repositório contém uma automação simples desenvolvida para um site de imóveis. A automação utiliza o navegador EDGE para acessar o site, realizar buscas e coletar informações como links dos imóveis, preços e data da consulta. Os dados são então armazenados em uma planilha. A automação foi implementada em Python.

## Como Usar

1. Clone o repositório:

```bash
git https://github.com/bispobr/python-automacao-site-imoveis.git
```
2. instale o selenium e openpyxl atraves do pip python
3. Defina o local de salvamento da planilha
2. execute o arquivo app.py
